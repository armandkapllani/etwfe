## Acknowledgements

This package was influenced by and builds on excellent work from the open source community:

- **Grant McDermott** ([@grantmcdermott](https://github.com/grantmcdermott)) — Author of the original [etwfe R package](https://github.com/grantmcdermott/etwfe), which served as a key reference for API design and implementation approach.

- **Alexander Fischer** ([@s3alfisc](https://github.com/s3alfisc)) — Author of [pyfixest](https://github.com/py-econometrics/pyfixest), which provides the high-dimensional fixed effects estimation that this package builds on.

- **Vincent Arel-Bundock** ([@vincentarelbundock](https://github.com/vincentarelbundock)) — Author of [marginaleffects](https://github.com/vincentarelbundock/marginaleffects), which informed the marginal effects methodology.
